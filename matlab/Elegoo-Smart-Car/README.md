This repository is for MATLAB files related to the operation os Elegoo Smart Car v4 used in class

* <example> Example MATLAB files that runs the smart car
* <calibration> Example range sensor calibration file
* <setup> Files related to [re-flashing Elegoo firmware for WiFi operation](https://rpi-robotics.notion.site/Updating-Elegoo-Smart-Car-Firmware-for-Tetherless-Operations-400abade4a9480a6ad73ff1171c1cb04?pvs=25)
